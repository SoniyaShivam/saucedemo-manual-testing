TC-004: Checkout with an Empty Cart

Objective: Verify that the application prevents checkout when the cart contains no products.

Precondition: The user is logged in, and the cart is empty.

Test Steps:
1. Add a product to the cart.
2. Remove the product.
3. Proceed to checkout.
4. Enter the required first name, last name, and postal code.
5. Continue to the Checkout Overview page.
6. Verify that no products are listed.
7. Click Finish.
8. Click Generate PDF Order on the confirmation page.

Expected Result: The application should prevent order completion when the cart is empty.

Actual Result: The order confirmation page appeared even though no products were listed. The generated PDF contained no products, and the total cost and tax were $0.00.

Status: NEEDS INVESTIGATION

Note: This is an observed potential defect in the demo application. Confirm the intended behavior before reporting it as a confirmed bug.
